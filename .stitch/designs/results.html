Root Cause Analysis

The analysis indicates significant cache eviction pressure occurring during the peak write period. The WiredTiger storage engine was unable to evict pages fast enough to keep up with the incoming request volume, leading to ticket exhaustion and elevated latency for application-level queries.

lightbulb

Primary Trigger Identified

Oplog application speed lagging behind primary write ops during large batch insert at 16:15 UTC.

Recommended Actions

  • 1
    Scale Oplog size to prevent frequent truncation
  • 2
    Tune WiredTiger cache eviction thread count
  • 3
    Monitor slow queries with high memory footprint
